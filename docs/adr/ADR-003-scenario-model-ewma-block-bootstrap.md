# ADR-003：情景模型用 EWMA 过滤 + 块自助法，零漂移，基差线性收敛

- Status: Accepted
- Date: 2026-10-08

## Context

要估计「到 11-20 时总金额的分布」，以及途中爆仓、穿仓的概率。路径约 30 个交易日，涉及 8 个相关品种，
历史数据约 830 个交易日。要能在几秒内评估上万个候选组合。

## Options Considered

1. 多元正态 + 协方差矩阵（含 Ledoit-Wolf 收缩）。
2. GARCH / DCC 参数模型。
3. 过滤历史模拟：EWMA 标准化残差，按日期整行做块自助法，路径上的波动率按 EWMA 递推。

## Decision

选方案 3：
- λ = 0.94，残差去均值，即零漂移，不预测涨跌；
- 块长 5，按日期整行抽样，保留品种之间的相关性和肥尾；
- 初筛 2000 条路径，终评 10000 条，种子固定。

股指 2612 的价格按「指数 × (1 + 当前基差 × 剩余交易日 ÷ 当前剩余交易日)」计算，即基差线性收敛；国债 2612 按主连收益滚动。
预先算好「路径 × 天 × 合约」的单手盈亏和单手保证金张量，评估一个组合就是张量乘手数向量。

## Why

- 保留了历史上真实出现过的肥尾和相关性，比如 2024-09 的暴涨；EWMA 又能反映当前的波动水平。
- 零漂移避免模型「猜方向」。贴水带来的 carry 通过基差收敛自然体现出来。
- 用张量计算，几千个候选能在几秒内评完。

## Consequences

- 不会出现历史上没有过的极端情景。
- 爆仓只在每天收盘检查，爆仓后权益冻结；这是简化，真实规则下爆仓后还可以继续交易。
- 基差线性收敛是近似。
