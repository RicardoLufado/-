# ADR-008：目标改为「稳过前 3000 名」，晋级线改用相对口径

- Status: Accepted
- Date: 2026-10-10
- Supersedes ADR-004（晋级线口径部分）

## Context

- 10-09 的周榜显示：用户总金额 204.3 万，比「完全不交易」高 +3.2%，已排第 1590 名。用三期前 100 名加本人名次，
  按 Student-t 拟合、差距按 √交易日 扩大，推算 11-20 时第 3000 名约比不交易账户高 0% 到 +2.4%，
  远低于 ADR-004 假设的 208–216 万。
- 每个参赛者的现货持仓相同（只因报名日期不同略有差异），现货涨跌互相抵消，排名实际只看期货账户。
- 参照上一届规则，初赛名次只决定能否晋级，奖项看复赛成绩。用户决定追求「稳」。
- 其他参赛者大多做多，所以晋级线会随大盘移动（「群体 β」），而且幅度未知。

## Options Considered

1. 保留总金额区间，只把数字调低，比如 198–204 万。缺点：现货的涨跌会被当成风险，模型会去对冲现货，方向错误。
2. 相对口径，人群不持仓：晋级线 = 不交易账户 + 期货盈利 c0。缺点：会推荐全部平仓，一旦大盘上涨、别人追上来就很危险。
3. 相对口径，并对人群持仓的几种假设等权平均：晋级线 = 不交易账户 + c0 + Nc × 沪深300 涨跌，
   c0 ~ U[0, 6 万]，Nc ∈ {0, 0.5, 1, 2} 手 IF。

## Decision

选方案 3：
- `config/strategy.yaml` 中 `threshold.mode: relative`，`excess_low: 0`，`excess_high: 60000`，`crowd_if_lots: [0, 0.5, 1, 2]`；
- `engine/threshold.py` 统一计算晋级概率；
- 状态按期货领先判断（追赶 / 持平 / 锁定）；
- 模式 D 在相对口径下只最小化期货权益的波动；
- 旧口径保留为 `mode: absolute`。

## Why

- 现货抵消后，模型不会再为了对冲现货去做无意义的交易。
- 对人群持仓取平均，得到的是在不同假设下都不差的稳健方案。按 10-09 的数据，「1 手 IF」的晋级概率是 84.7%，
  全部平仓 77.5%，持有 3 手 IM 约 62%。
- 与用户「稳过线」的目标一致。

## Consequences

- 推荐从「3 手 IM」变成「1 手 IF」，爆仓风险从约 15% 降到 0%。
- 晋级线区间和人群持仓的假设都是推算的，必须每周用榜单校准，数据记在 `state/leaderboard.json`。
- 页面上的晋级线显示为「期货盈利区间 ≈ 按当前现货折算的总金额区间」。
- 「赚 20 万以上」的上涨空间被主动放弃（用户已认可）。
