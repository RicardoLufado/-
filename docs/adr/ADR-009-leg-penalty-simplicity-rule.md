# ADR-009：搜索加「简洁规则」，每多一个品种扣 0.3 个百分点

- Status: Accepted
- Date: 2026-10-10

## Context

在相对口径下，用真实数据搜出的最优解是「1 手 IF + 二债空 1 + 五债多 2」，晋级概率 84.84%；
单独 1 手 IF 是 84.74%。两条国债腿只多 0.1 个百分点，属于蒙特卡洛噪音的量级，三个随机种子给出的组合也不一致。
用户不是程序员，多下三笔单会增加困惑和操作风险。

## Options Considered

1. 照常输出最优解。
2. 事后人工删掉「看起来没用」的腿。
3. 在搜索目标里加入复杂度惩罚：每个非零品种扣 `leg_penalty`。

## Decision

选方案 3：
- `config/strategy.yaml` 的 `search.leg_penalty: 0.003`；
- `engine.optimize.score()` 在初筛、复评、坐标下降时都扣分；
- 页面和稳健性报告里的晋级概率仍然是**不扣分**的原值。

## Why

- 规则统一、可复现，不靠人工判断。
- 0.3 个百分点大于这里的 Monte Carlo 误差（约 0.1–0.4 个百分点），只过滤掉噪音级的改进。

## Consequences

- 推荐变成「1 手 IF」，三个种子的结果一致。
- 如果某条腿真的有价值（改进超过 0.3 个百分点/品种），仍然会被保留。
- 改 `leg_penalty` 会改变推荐，应该在 TASK.md 或新 ADR 里说明。
