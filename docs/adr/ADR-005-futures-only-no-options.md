# ADR-005：只做 2612 股指 / 国债期货，不做期权

- Status: Accepted
- Date: 2026-10-10

## Context

开工文档的路线图第 1 项是期权（IO/HO/MO，用 Black-76 重估）。2611 合约在 11-20 到期，恰好是初赛最后一天，
模拟系统怎么处理到期合约还没确认。用户在 10-10 明确表示不做期权（「我们没有期权赛道，我理解错了」）。

## Options Considered

1. 另做一个期权页面，买入虚值期权，期权和期货共用同一个账户一起优化。
2. 只做期货。

## Decision

只做 2612 期货。期权相关的计划，包括数据接口调研，全部搁置。`account.json` 里不写期权持仓。

## Why

- 用户明确不做期权。
- 2611 到期口径不清；期权链数据和隐含波动率估计会增加很多复杂度和数据风险。
- 期货加上相对晋级线口径（ADR-008），已经能表达「稳过线」的策略。

## Consequences

- 无法用「买期权」获得「亏损有上限、上涨不封顶」的收益形态（这是用户问到的「既稳又有上涨空间」）。
- `engine.orders` 对模型里没有的合约代码会给出平仓指令。如果以后要做期权，得先改这一点，并且新建 ADR。
