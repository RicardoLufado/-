# ADR-002：用 AKShare（新浪）取数，股指历史用指数；每个接口都有缓存回退

- Status: Accepted
- Date: 2026-10-08

## Context

模型需要 8 个品种的历史日线、2612 合约的最新收盘价、交易日历和盘中价。数据源可能不稳定。
用户要求不许编造数据。主力连续合约每次换月都会出现跳空。

## Options Considered

1. 股指历史用新浪主力连续合约（IF0 等）。
2. 股指历史用对应**指数**，2612 价格通过「指数 + 基差」推出。
3. 用付费数据源（Wind、Tushare Pro）。

失败处理的两种做法：
- 失败就整次报错；
- 每个接口独立重试，失败用缓存，并写进 warnings。

## Decision

- 股指历史用指数：`stock_zh_index_daily`，sh000300 / sh000016 / sh000905 / sh000852。
- 国债历史用新浪主连 TS0/TF0/T0/TL0，日收益绝对值超过 6 倍 MAD 的点整行剔除。
- 2612 合约用 `futures_zh_daily_sina` 的收盘价；盘中价 `futures_zh_spot` 只用于展示和参考价。
- `Fetcher` 对每个接口：重试 3 次、超时 20 秒、间隔 1 秒；成功写 `data/cache/`，失败读缓存并写 warnings；没有缓存就记为「数据缺失」。
- 关键序列（沪深300、T/TF）缺失时，引擎报错，交给 fallback。

## Why

- 指数没有换月跳空，股指收益更干净；基差可以单独建模（ADR-003）。
- AKShare 免费；列名已经对照 1.19 源码核对过，第一次真实运行时也打印了列名确认。
- 每个接口独立回退，比「一个接口失败就全部失败」更稳，而且所有回退都在页面上标明。

## Consequences

- 国债主连没有复权，剩下的小跳空仍混在历史里（写在「局限」里）。
- 新浪的指数日线要到**晚上**才更新当天收盘，所以收盘后的定时放在晚上（ADR-007）。
- 新浪免费盘中价可能延迟；参考价都标明了来源和时间。
