        方法说明

        这是排名制锦标赛：只有前 3000 名晋级，回报是凸的。所以目标函数取「晋级概率」，而不是收益或夏普比率。

        晋级线（相对口径）：现货账户人人相同、涨跌互相抵消，名次只看期货账户。按周榜前 100 名与本人名次推算，第 3000 名 ≈「不交易账户 + 期货盈利 c」，c 在估计区间内均匀分布；其他参赛者大多做多，晋级线还会随大盘移动，模型对「人群平均持有 0 / 0.5 / 1 / 2 手 IF 多单」几种情况取平均。每周用新榜单校准。

        模式 A：最大化排在晋级线之上的概率（对区间均匀分布求平均，等价于 mean(clip((x − 下沿) ÷ (上沿 − 下沿), 0, 1))）。初赛名次只决定能否晋级、奖项看复赛，所以目标是稳过线，不追求更高收益。 Browne (1999)《Reaching goals by a deadline》：目标是在截止日前达到某个水平时，最优策略是落后时加大风险、领先时锁定。系统每次运行都会根据当前权益和剩余天数重新优化，这个行为会自然出现。

        模式 D：同样的整数枚举，最小化期末波动（相对口径下只看期货账户，通常就是空仓）。

        情景：2023-05 以来 8 个序列（股指用指数、国债用新浪主连）的对数收益，EWMA（λ=0.94）标准化并去均值（零漂移，不预测涨跌），按日期整行做块长 5 的块自助法，路径上的波动率按 EWMA 递推。股指 2612 价格 = 指数 × (1 + 当前基差 × 剩余交易日 ÷ 当前剩余交易日)，即基差线性收敛；国债 2612 按主连收益滚动。

        爆仓 / 穿仓：每天收盘若权益 < 保证金 × liq_ratio，当天按收盘价全部平仓、此后权益冻结；若此时权益 < 0 记为穿仓，负权益保留。

        搜索：最多两个股指品种（各 −3 到 +3 手）× 最多一个国债品种（保证金上限内约 15 个等距手数），开仓保证金 ≤ 70% 期货权益；2,000 条路径初筛 → 前 30 名换 10,000 条路径复评 → 8 个维度 ±1 手坐标下降；再换 3 个随机种子重算最优解。

        其他方法（Markowitz 均值方差、Kelly、Ledoit-Wolf、Black-Litterman、时间序列动量）将作为后续版本的对照模式。
